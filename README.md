# ЛР5 — Летописные источники

React + TypeScript + Vite + React-Bootstrap. Две страницы гостя, данные только из `src/mocks/chronicles.ts`. API, PostgreSQL, Redis и S3 для запуска не нужны. Redux и Context не используются.

## Запуск
```powershell
cd C:\Users\Dmitry\Desktop\web-lab1\frontend
npm install
npm run dev
```
Адрес: http://127.0.0.1:5173. Проверка сборки: `npm run build`.

## Страницы и меню
- `#/catalog` — плитка семи источников: изображение, название, количество лайков, кнопка «Смотреть». Поле «Дата начала летописи» с календарём и кнопка «Найти» фильтруют локальные моки по году. Пустое поле снимает фильтр. По кнопке «Смотреть» открывается выбранная запись ленты.
- `#/feed?id=1` — один источник: изображение, видео с управлением, название, краткое описание, год авторства, год начала, количество лайков. Кнопка «Следующий» циклически переключает записи.
- Нижнее меню: «Лента», «Добавление», «Плитка», «Вход». Доступны только лента и плитка; два остальных пункта отключены.

## Компоненты, props и хуки
`YearFilter` получает `value`, `onChange`, `onSubmit` от `CatalogPage`. `SourceImage` получает `src` и `alt`. `FeedPage` получает `id` и `onNext`. Состояние фильтра и маршрута хранится в `useState`. `useEffect` подписывается на hashchange с очисткой, сбрасывает ошибку картинки при изменении src и перезагружает видео при смене записи. `useRef` хранит ссылку на HTMLVideoElement. Это все используемые хуки.

## Медиа по умолчанию
Локальные `public/media/chronicle_default.jpg` и `chronicle_default.mp4` используются при пустых полях и ошибке загрузки медиа. Седьмой mock содержит null в обоих полях — откройте его через плитку для демонстрации. Все остальные медиа тоже локальные, без S3.

Код дефолтов: `SourceImage.tsx`, `FeedPage.tsx`; фильтра: `YearFilter.tsx`, `CatalogPage.tsx`; хуков: `App.tsx`, `SourceImage.tsx`, `FeedPage.tsx`, `CatalogPage.tsx`.
